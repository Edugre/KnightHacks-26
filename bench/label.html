Bench Labeler

Pick an object on the right, then drag on empty space to draw its box (one box per object per frame). Drag a box to move it, drag a corner to resize. Gray dashed outlines are the previous frame's boxes. Colored dashed boxes are detector drafts: check the whole frame for anything it missed, then confirm. Only confirmed frames are scored, and a confirmed frame with no boxes means "nothing to hide here".
Keys: ← → move, Enter confirm and next, C copy the previous frame's boxes, Del delete the selected object's box, 1-9 select object, S save.
